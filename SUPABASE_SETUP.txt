IMPORTANT AUTH URL SETTING
--------------------------
In Supabase Dashboard > Authentication > URL Configuration:
1. Set Site URL to the deployed NOVINEXT website URL.
2. Add the same deployed URL to Redirect URLs.

Magic-link sign-in uses the current deployed origin/path as emailRedirectTo.
When index.html is opened directly via file://, email redirect is intentionally not set because browsers cannot use a file URL as an Auth redirect.

FIRST ADMIN
-----------
For security, the frontend never contains a service_role key and does not automatically make the first registrant an admin.
After the intended administrator has registered with an email, promote that specific account to app_role='admin' and approval_status='approved' using a trusted admin action / database operation.
